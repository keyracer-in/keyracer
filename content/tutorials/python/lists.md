# Python Lists

## Creating Lists

```python
fruits = ["apple", "banana", "cherry"]
numbers = [1, 2, 3, 4, 5]
mixed = [1, "hello", True, 3.14]
```

## Accessing Elements

```python
first = fruits[0]
last = fruits[-1]
```

## List Methods

```python
fruits.append("orange")
fruits.remove("banana")
fruits.sort()
```
