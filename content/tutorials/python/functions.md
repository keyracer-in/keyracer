# Python Functions

## Defining Functions

```python
def greet():
    print("Hello!")
```

## Parameters

```python
def greet(name):
    print(f"Hello, {name}!")
```

## Return Values

```python
def add(a, b):
    return a + b

result = add(5, 3)
```

## Default Parameters

```python
def greet(name="Guest"):
    print(f"Hello, {name}!")
```
