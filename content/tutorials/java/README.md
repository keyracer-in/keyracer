# Java Tutorial Content Structure

This directory contains the Java tutorial content extracted from `java-tutorial.html`.

## File Structure

The following markdown files correspond to sections in the original HTML:

1. `introduction.md` - What is Java? (Section: #introduction)
2. `getting-started.md` - Getting Started with Java (Section: #getting-started)
3. `syntax.md` - Java Syntax: The Basics (Section: #syntax)
4. `variables.md` - Java Variables (Section: #variables)
5. `data-types.md` - Java Data Types (Section: #data-types)
6. `operators.md` - Java Operators (Section: #operators)
7. `control-flow.md` - Control Flow (Section: #control-flow)
8. `methods.md` - Methods (Section: #methods)
9. `classes-objects.md` - Classes & Objects (Section: #classes-objects)
10. `arrays.md` - Arrays (Section: #arrays)

## Content Guidelines

- All code blocks use ` ```java ` for syntax highlighting
- Emoji icons are preserved from the original content
- Tables are converted to markdown table syntax
- Links are converted to markdown link syntax
- Headings follow markdown hierarchy (h1 = #, h2 = ##, h3 = ###)
